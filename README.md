# ReTSM

ReTeamSpeakManager

## Prerequisites

Ensure you have the following installed:
1. [Flutter SDK](https://docs.flutter.dev/get-started/install) (3.22+ recommended)
2. [Rust](https://www.rust-lang.org/tools/install)
3. `flutter_rust_bridge_codegen` installed globally. Keep it aligned with the generated bridge version in this repo:
   ```bash
   cargo install 'flutter_rust_bridge_codegen@^2.12.0'
   ```
4. Windows portable builds require [Enigma Virtual Box](https://enigmaprotector.com/en/aboutvb.html) with `enigmavbconsole.exe` available at the default install path used by `build.ps1`.

## Setup

Since this project uses `flutter_rust_bridge` to connect Dart UI with Rust backend logic, run the code generator whenever you change files under `rust/src/api/` or otherwise update the bridge contract.

1. Install Dart dependencies:
   ```bash
   flutter pub get
   ```

2. Generate the Rust-Dart bridge bindings:
   ```bash
   flutter_rust_bridge_codegen generate
   ```

3. Run the application (Desktop):
   ```bash
   flutter run -d windows # Or macos/linux
   ```

## Windows Portable Build

The repository includes `build.ps1` for a Windows release build plus Enigma Virtual Box packaging.

1. Build the app and package the portable executable:
   ```powershell
   .\build.ps1
   ```
2. The script produces `ReTSM-Portable.exe` in the repository root.
3. `build_dynamic.evb` is generated by the script and is not meant to be edited manually.
